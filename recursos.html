Skill · Hermes Agent

Video Edit con IA

Skill para agentes CLI que automatiza la edicion de video con Remotion: overlays Liquid Glass, subtitulos, key phrases, zooms y CTA. Arquitectura de composiciones reutilizables. Funciona en Hermes Agent, Claude Code, Codex, PI Agent y cualquier CLI con acceso al filesystem.

Descargas = clonar el repo o copiar la carpeta

Como instalar en cualquier CLI

01
Hermes Agent

Copiar la carpeta a ~/.hermes/skills/creative/. El agente la detecta automaticamente.

cp -r remotion-video-editing ~/.hermes/skills/creative/
02
Claude Code · Codex · PI Agent

Cargar SKILL.md como contexto inicial. El agente sigue las instrucciones del archivo paso a paso.

cat SKILL.md | claude --instructions -
03
Cualquier CLI

La skill es un prompt estructurado. Copiar el contenido de SKILL.md al inicio de tu conversacion con cualquier LLM.

# Copiar SKILL.md y pegar como system prompt
